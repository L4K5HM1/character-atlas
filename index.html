DATA NOTES — Bleach base-form stats for the Soul Society–arc captains are drawn from official combat-power scores published in Bleach: Official Character Book "SOULs," visualized as a six-axis radar (STR / DEF / SPD / TEC / INT / POW).   Naruto stats are the official Ninjutsu / Taijutsu / Genjutsu / Intelligence / Strength / Speed / Stamina / Hand Seals "Skill Parameters" from Naruto Databooks I–III where available (each scored 0–5 in 0.5 increments, shown as ten-tick meters), with later power-ups estimated in the same format.   One Piece has no official numeric databook, so every entry is a fan-consensus estimate — shown as a Haki triangle (Observation / Armament / Conqueror's) plus the same six core stats as bars instead of a radar. The one universal number across all three — the "Power Level" gauge — is a custom cross-series scale meant purely for comparing characters between universes; everything else uses each series' own system.
